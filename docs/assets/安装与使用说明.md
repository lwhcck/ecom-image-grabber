# 图提取 ImageGrab · 安装与使用说明

一个 Chrome 浏览器扩展：在**淘宝 / 天猫 / 京东 / 拼多多商家版**的商品详情页，一键提取页面内所有商品图片，
在新标签页集中展示、勾选，批量下载为 **PNG** 格式。

---

## 一、文件结构

```
plugin/
├── manifest.json      # 扩展清单（Manifest V3）：权限、匹配域名、注入配置
├── content.js         # 内容脚本：注入右下角「获取图片」悬浮按钮 + 扫描提取页面图片
├── content.css        # 悬浮按钮与提示条样式
├── background.js      # Service Worker：图片转 PNG、打开图片库、批量下载
├── gallery.html       # 图片库页面：网格展示 + 勾选
├── gallery.js         # 图片库交互：全选 / 反选 / 下载选中 + 进度反馈
├── gallery.css        # 图片库样式（响应式网格）
└── icons/             # 扩展图标 16 / 32 / 48 / 128
```

## 二、安装步骤

1. 把 `plugin` 整个文件夹保存到本地（例如 `D:\imagegrab\plugin`）。
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
3. 打开右上角的**开发者模式**。
4. 点**加载已解压的扩展程序**，选择 `plugin` 文件夹。
5. 加载成功后扩展列表会出现「图提取 ImageGrab · 电商图片下载插件」。

> Edge 浏览器同样适用：地址栏输入 `edge://extensions`，步骤一致。

## 三、使用步骤

1. 打开一个**商品详情页**：
   - 淘宝 / 天猫：`item.taobao.com/...`、`detail.tmall.com/...`
   - 京东：`item.jd.com/...`
   - 拼多多商家版：`*.pinduoduo.com`、`*.yangkeduo.com`
2. 页面**右下角**会出现「获取图片」悬浮按钮（只有详情页会显示，首页 / 列表页不显示）。
3. 点击按钮，插件会：
   - 自动滚动整页触发**懒加载**；
   - 扫描 `<img>`、`srcset`、`data-src`、`data-lazy-src`、`data-original`、CSS `background-image` 等来源；
   - 过滤图标、logo、占位图、1×1 像素图与小于 100×100 的小图；
   - 补全相对路径为绝对 URL 并去重。
4. 自动打开**图片库**新页面（`gallery.html`）：
   - 网格展示缩略图、尺寸、序号；
   - 顶部支持**全选 / 反选 / 清空**，实时显示已选数量；
   - 点**下载选中（PNG）**批量保存。
5. 下载的图片统一转为 PNG，文件名形如 `商品图_001.png`、`商品图_002.png`，序号补零，保存在浏览器默认下载目录。

> 也可以直接点击浏览器工具栏上的扩展图标，随时打开图片库查看上次提取结果。

## 四、技术要点

| 要点 | 做法 |
|---|---|
| 权限最小化 | 只用 `activeTab`、`scripting`、`downloads`、`storage`；`host_permissions` 只覆盖三层域名：① 三个平台的站点域名；② 这些平台的**图片 CDN**（`*.alicdn.com`、`*.tbcdn.cn`、`*.360buyimg.com`、`*.pddpic.com`）——商品图实际托管在 CDN 上，Service Worker 的 `fetch` 必须有权访问，否则抓图会以 `Failed to fetch` 失败；**没有申请 `tabs`**——复用图片库标签页时只记住自己创建的标签页 id，用 `chrome.tabs.get` 探测存在性 |
| Service Worker 模块化 | `background.js` 使用 ESM 语法（`import` / `export`），因此 manifest 里必须声明 `"background": { "service_worker": "background.js", "type": "module" }`。漏掉 `type: module` 时 Chrome 会按 classic worker 解析，**直接语法错误、Service Worker 起不来**（这一点已用真机加载验证过） |
| 懒加载兼容 | 提取前先滚动整页，同时兼容 `data-src` / `data-lazy-src` / `data-original` / `data-ks-lazyload` 等十余种属性命名 |
| 小图过滤 | 用 `new Image()` 探测真实 `naturalWidth/naturalHeight`，过滤 1×1、小图与细长装饰条 |
| 跨域转 PNG | 在 Service Worker 中用 `fetch` + `createImageBitmap` + `OffscreenCanvas` 转换，不受页面 CSP 与画布污染限制 |
| 批量下载 | Service Worker 把 PNG Blob 转成 data URL 后交给 `chrome.downloads.download` 保存 |
| 性能控制 | 尺寸探测 8 并发、PNG 转换 4 并发，图片库缩略图 4 并发且超过 60 张时回退直连预览 |

> **演示模式**：图片库地址后加 `?mock=1` 时会读取 `gallery-mock-data.js` 里的演示数据，
> 方便在没有真实电商页面时截图取证。正常使用（扩展图标 / 详情页按钮打开）不带该参数，
> 走 Service Worker 的真实数据。

## 五、常见问题

**Q：点了按钮没反应？**
A：确认当前是商品详情页（URL 或页面结构命中详情页特征）。首页、搜索结果页、购物车页不会注入按钮。

**Q：提取到的图片比页面上看到的少？**
A：小于 100×100 的图片会被当作图标过滤掉；如需保留，可修改 `content.js` 里的 `MIN_SIZE` 常量。

**Q：下载下来的图片打不开？**
A：个别平台的图片链接带防盗链或已失效，插件会跳过并在结果中提示失败数量。

**Q：下载时浏览器提示「是否允许下载多个文件」？**
A：这是 Chrome 对批量下载的安全提示，点「允许」即可；也可在 `chrome://settings/content/automaticDownloads` 里把本站加入允许列表。

## 六、隐私说明

所有图片提取、转换都在**浏览器本地**完成，插件不向任何服务器上传页面内容或图片。
